Apprendre HTML

Leçon 1 : Les Titres

Les titres vont de h1 à h6.

<h1>Titre Principal</h1>
<h2>Sous titre</h2>

Leçon 2 : Les Paragraphes

La balise p permet d’écrire du texte.

<p>Bonjour le monde</p>

Leçon 3 : Les Liens

Créer des liens avec la balise a.

<a href="https://google.com">
Google
</a>

Leçon 4 : Les Images

Afficher des images dans HTML.

<img src="photo.jpg">

Leçon 5 : Les Boutons

Créer un bouton HTML.

<button>Clique</button>

Leçon 6 : Les Listes

Créer des listes avec ul et li.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Leçon 7 : Les Tableaux

Créer un tableau simple.

<table border="1">
 <tr>
   <td>Nom</td>
 </tr>
</table>
