Leçon 1 : Les Titres

En HTML, les titres servent à organiser les textes sur une page web. Ils permettent de créer une hiérarchie comme dans un livre. La balise h1 représente le titre principal de la page. Les balises h2, h3, h4, h5 et h6 servent pour les sous-titres.

Plus le chiffre est petit, plus le titre est important. Il est conseillé d’avoir un seul h1 principal par page. 

<h1>Titre Principal</h1>
<h2>Sous titre</h2>
<h3>Petit sous titre</h3>

Leçon 2 : Les Paragraphes

La balise p permet d’écrire des paragraphes. C’est la balise la plus utilisée pour afficher du texte sur un site.

Chaque paragraphe possède automatiquement un espace avant et après. Cela rend la lecture plus agréable pour les visiteurs. 

<p>Bonjour le monde</p>

<p>
Bienvenue sur mon premier site web.
</p>

Leçon 3 : Les Liens

Les liens permettent de naviguer d’une page à une autre. Ils utilisent la balise a.

L’attribut href contient l’adresse du lien. On peut ouvrir un autre site, une autre page ou un fichier. 

<a href="https://google.com">
Google
</a>

Leçon 4 : Les Images

Les images rendent un site plus joli et plus vivant. On utilise la balise img pour afficher une image.

L’attribut src indique le chemin de l’image. Il est conseillé d’ajouter aussi l’attribut alt pour décrire l’image. 

<img src="photo.jpg" alt="Photo">

Leçon 5 : Les Boutons

Les boutons permettent aux utilisateurs de cliquer pour effectuer une action.

Les boutons peuvent servir à envoyer un formulaire, ouvrir un menu ou lancer du JavaScript. 

<button>Clique ici</button>

Leçon 6 : Les Listes

Les listes permettent d’organiser plusieurs éléments. La balise ul crée une liste non ordonnée.

Chaque élément de la liste est placé dans une balise li. 

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Leçon 7 : Les Tableaux

Les tableaux servent à afficher des données sous forme de lignes et colonnes.

La balise table crée le tableau, tr représente une ligne, td représente une cellule. 

<table border="1">

<tr>
   <td>Nom</td>
   <td>Age</td>
</tr>

<tr>
   <td>Ali</td>
   <td>20</td>
</tr>

</table>

Leçon 8 : Les Formulaires

Les formulaires permettent aux utilisateurs d’envoyer des informations.

On peut créer des formulaires de connexion, d’inscription ou de contact. 

<form>

<input type="text">

</form>

Leçon 9 : Les Inputs

Les inputs servent à créer des champs de saisie. L’utilisateur peut écrire du texte, un email ou un mot de passe.

Il existe plusieurs types d’inputs. 

<input type="text">

<input type="email">

<input type="password">

Leçon 10 : Les Vidéos

HTML permet d’ajouter facilement des vidéos. La balise video est utilisée avec l’attribut controls.

Les contrôles permettent de lire, mettre pause et régler le volume. 

<video controls width="300">

<source src="video.mp4">

</video>

Leçon 11 : Les Audios

La balise audio permet d’ajouter des sons ou musiques.

L’utilisateur peut écouter directement depuis le navigateur. 

<audio controls>

<source src="music.mp3">

</audio>

Leçon 12 : Les Div

La balise div sert à organiser les éléments d’une page.

Elle est très utilisée avec CSS pour créer des sections, colonnes et boîtes. 

<div>

Contenu ici

</div>

Leçon 13 : Les Span

La balise span sert à modifier une petite partie du texte.

Contrairement à div, span reste sur la même ligne. 

<p>
Bonjour <span>mon ami</span>
</p>

Leçon 14 : Les Classes

Les classes permettent de cibler des éléments avec CSS.

Plusieurs éléments peuvent partager la même classe. 

<div class="box">

Contenu

</div>

Leçon 15 : Les IDs

Les IDs servent à identifier un élément unique.

Contrairement aux classes, un ID doit être utilisé une seule fois. 

<div id="menu">

Menu principal

</div>

Leçon 16 : Les Commentaires

Les commentaires servent à écrire des notes dans le code HTML. Ces notes ne sont pas visibles sur la page web.

Les développeurs utilisent les commentaires pour expliquer certaines parties du code ou organiser leur travail. 

<!-- Ceci est un commentaire -->

Leçon 17 : Strong

La balise strong permet de mettre un texte en gras.

Elle indique aussi que le texte est important. 

<strong>Attention</strong>

Leçon 18 : Em

La balise em sert à mettre un texte en italique.

Elle permet aussi d’insister sur un mot ou une phrase. 

<em>Texte important</em>

Leçon 19 : Br

La balise br permet de faire un saut de ligne.

Elle est utile pour écrire des poèmes, des adresses ou du texte sur plusieurs lignes. 

Bonjour<br>
Bienvenue

Leçon 20 : Hr

La balise hr crée une ligne horizontale.

Elle permet de séparer différentes sections d’une page. 

<hr>

Leçon 21 : Section

La balise section sert à regrouper une partie importante du contenu.

Elle améliore l’organisation de la page. 

<section>

Contenu

</section>

Leçon 22 : Header

La balise header représente l’en-tête d’une page.

Elle contient souvent le logo, le titre ou le menu principal. 

<header>

Mon site

</header>

Leçon 23 : Footer

La balise footer représente le pied de page.

On y place souvent les contacts, les droits d’auteur ou les liens utiles. 

<footer>

Copyright 2026

</footer>

Leçon 24 : Nav

La balise nav sert à créer un menu de navigation.

Elle contient généralement plusieurs liens. 

<nav>

<a href="#">Accueil</a>

</nav>

Leçon 25 : Article

La balise article représente un contenu indépendant.

Elle est souvent utilisée pour les articles de blog ou les actualités. 

<article>

Article ici

</article>

Leçon 26 : Aside

La balise aside sert à afficher un contenu secondaire.

Elle peut contenir une publicité, des liens ou une barre latérale. 

<aside>

Menu secondaire

</aside>

Leçon 27 : Main

La balise main contient le contenu principal de la page.

Elle aide les moteurs de recherche et améliore l’accessibilité. 

<main>

Contenu principal

</main>

Leçon 28 : Small

La balise small affiche un texte plus petit.

Elle est souvent utilisée pour les notes ou informations secondaires. 

<small>Texte petit</small>

Leçon 29 : Mark

La balise mark permet de surligner un texte.

Le navigateur affiche généralement un fond jaune. 

<mark>Important</mark>

Leçon 30 : Sup et Sub

Les balises sup et sub servent à écrire des exposants et indices.

Elles sont utiles en mathématiques et en chimie. 

X<sup>2</sup>

H<sub>2</sub>O

Leçon 31 : Icônes

Les icônes améliorent l’apparence d’un site.

On utilise souvent Font Awesome ou Bootstrap Icons. 

<i class="fa fa-home"></i>

Leçon 32 : Bouton Submit

Le bouton submit sert à envoyer un formulaire.

Lorsque l’utilisateur clique, les données sont transmises. 

<button type="submit">

Envoyer

</button>

Leçon 33 : Checkbox

Les cases à cocher permettent de sélectionner plusieurs choix. 

<input type="checkbox">

Leçon 34 : Radio

Les boutons radio permettent de choisir une seule option. 

<input type="radio">

Leçon 35 : Select

La balise select crée une liste déroulante.

Elle permet de gagner de l’espace sur la page. 

<select>

</select>

Leçon 36 : Option

La balise option représente un choix dans une liste déroulante. 

<option>HTML</option>

Leçon 37 : Textarea

Textarea permet d’écrire de longs textes.

Très utile pour les commentaires ou messages. 

<textarea></textarea>

Leçon 38 : Label

La balise label sert à nommer un champ de formulaire. 

<label>Nom</label>

Leçon 39 : Placeholder

Placeholder affiche un texte temporaire dans un champ. 

<input placeholder="Votre nom">

Leçon 40 : Required

Required rend un champ obligatoire.

Le formulaire ne peut pas être envoyé si le champ est vide. 

<input required>

Leçon 41 : Email

Le type email vérifie automatiquement le format d’une adresse email. 

<input type="email">

Leçon 42 : Password

Le type password masque les caractères saisis par l’utilisateur. 

<input type="password">

Leçon 43 : Number

Le type number permet de saisir uniquement des nombres. 

<input type="number">

Leçon 44 : Date

Le type date affiche un calendrier.

L’utilisateur peut sélectionner facilement une date. 

<input type="date">

Leçon 45 : Color

Le type color ouvre un sélecteur de couleurs. 

<input type="color">

Leçon 46 : File

Le type file permet d’importer un fichier. 

<input type="file">

Leçon 47 : Range

Le type range crée un curseur.

Il est souvent utilisé pour le volume ou les réglages. 

<input type="range">

Leçon 48 : Progress

La balise progress crée une barre de progression. 

<progress value="50" max="100">

</progress>

Leçon 49 : Details

La balise details crée une zone qu’on peut ouvrir ou fermer.

Contenu caché

</details>

Summary représente le titre visible d’une balise details.

Quand l’utilisateur clique, le contenu apparaît. 

<details>

Texte caché

</details>
