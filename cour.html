Apprendre HTML - 50 Leçons Complètes

Leçon 1 : Les Titres

Les titres permettent d’organiser une page web. Ils vont de h1 à h6. Le h1 représente le titre principal. 

<h1>Titre Principal</h1>
<h2>Sous titre</h2>

Leçon 2 : Les Paragraphes

La balise p sert à écrire du texte. Chaque paragraphe possède automatiquement un espace. 

<p>Bonjour le monde</p>

Leçon 3 : Les Liens

Les liens permettent d’ouvrir une autre page web. La balise utilisée est a. 

<a href="https://google.com">
Google
</a>

Leçon 4 : Les Images

La balise img permet d’afficher des images. L’attribut src contient le chemin de l’image. 

<img src="photo.jpg">

Leçon 5 : Les Boutons

Les boutons servent à effectuer des actions. 

<button>Clique ici</button>

Leçon 6 : Les Listes

Les listes servent à organiser plusieurs éléments. 

<ul>
<li>HTML</li>
<li>CSS</li>
</ul>

Leçon 7 : Les Tableaux

Les tableaux affichent des données en lignes et colonnes. 

<table border="1">
<tr>
<td>Nom</td>
</tr>
</table>

Leçon 8 : Les Formulaires

Les formulaires permettent d’envoyer des informations. 

<form>
<input type="text">
</form>

Leçon 9 : Les Inputs

Les inputs servent à saisir des données. 

<input type="email">

Leçon 10 : Les Vidéos

HTML permet d’ajouter des vidéos. 

<video controls>
</video>

Leçon 11 : Les Audios

La balise audio sert à lire du son. 

<audio controls>
</audio>

Leçon 12 : Les Div

Div sert à organiser les éléments d’une page. 

<div>Contenu</div>

Leçon 13 : Les Span

Span permet de modifier une petite partie du texte. 

<span>Texte</span>

Leçon 14 : Les Classes

Les classes servent à cibler des éléments avec CSS. 

<div class="box"></div>

Leçon 15 : Les IDs

Les IDs servent à identifier un élément unique. 

<div id="menu"></div>

Leçon 16 : Les Commentaires

Les commentaires servent à écrire des notes dans le code. 

<!-- commentaire -->

Leçon 17 : Strong

Strong met un texte en gras. 

<strong>Texte</strong>

Leçon 18 : Em

Em met un texte en italique. 

<em>Texte</em>

Leçon 19 : Br

Br crée un saut de ligne. 

Bonjour<br>Monde

Leçon 20 : Hr

Hr crée une ligne horizontale. 

<hr>

Leçon 21 : Section

Section organise les parties d’une page. 

<section></section>

Leçon 22 : Header

Header représente l’en-tête du site. 

<header></header>

Leçon 23 : Footer

Footer représente le pied de page. 

<footer></footer>

Leçon 24 : Nav

Nav sert à créer un menu. 

<nav></nav>

Leçon 25 : Article

Article représente un contenu indépendant. 

<article></article>

Leçon 26 : Aside

Aside affiche un contenu secondaire. 

<aside></aside>

Leçon 27 : Main

Main contient le contenu principal. 

<main></main>

Leçon 28 : Small

Small affiche un texte plus petit. 

<small>Texte</small>

Leçon 29 : Mark

Mark surligne un texte. 

<mark>Important</mark>

Leçon 30 : Sup et Sub

Sup crée un exposant et Sub un indice. 

X<sup>2</sup>
H<sub>2</sub>O

Leçon 31 : Icônes

Les icônes améliorent le design du site. 

<i></i>

Leçon 32 : Submit

Submit envoie un formulaire. 

<button type="submit">
Envoyer
</button>

Leçon 33 : Checkbox

Checkbox permet plusieurs choix. 

<input type="checkbox">

Leçon 34 : Radio

Radio permet un seul choix. 

<input type="radio">

Leçon 35 : Select

Select crée une liste déroulante. 

<select></select>

Leçon 36 : Option

Option représente un choix. 

<option>HTML</option>

Leçon 37 : Textarea

Textarea permet d’écrire de longs textes. 

<textarea></textarea>

Leçon 38 : Label

Label nomme un champ de formulaire. 

<label>Nom</label>

Leçon 39 : Placeholder

Placeholder affiche un texte temporaire. 

<input placeholder="Votre nom">

Leçon 40 : Required

Required rend un champ obligatoire. 

<input required>

Leçon 41 : Email

Email vérifie une adresse email. 

<input type="email">

Leçon 42 : Password

Password masque le texte saisi. 

<input type="password">

Leçon 43 : Number

Number permet uniquement les nombres. 

<input type="number">

Leçon 44 : Date

Date ouvre un calendrier. 

<input type="date">

Leçon 45 : Color

Color permet de choisir une couleur. 

<input type="color">

Leçon 46 : File

File importe un fichier. 

<input type="file">

Leçon 47 : Range

Range crée un curseur. 

<input type="range">

Leçon 48 : Progress

Progress crée une barre de progression. 

<progress value="50" max="100">
</progress>

Leçon 49 : Details

Details crée un contenu ouvrable. 

<details></details>

Leçon 50 : Summary

Summary représente le titre d’un details. 

<summary>Voir plus</summary>
