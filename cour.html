Leçon 1 : Structure HTML

Une page HTML commence toujours par une structure de base.

<!DOCTYPE html>
<html>
<head>
    <title>Ma page</title>
</head>
<body>

</body>
</html>

Leçon 2 : Les Titres

HTML possède plusieurs niveaux de titres.

<h1>Grand titre</h1>
<h2>Titre moyen</h2>
<h3>Petit titre</h3>

Leçon 3 : Les Paragraphes

Les paragraphes servent à écrire du texte.

<p>Bonjour tout le monde</p>

Leçon 4 : Les Liens

La balise a permet de créer des liens.

<a href="https://google.com">
    Aller sur Google
</a>

Leçon 5 : Les Images

La balise img affiche une image.

<img src="image.jpg" alt="photo">

Leçon 6 : Les Listes

Créer une liste avec ul et li.

<ul>
   <li>HTML</li>
   <li>CSS</li>
</ul>

Leçon 7 : Les Tableaux

Les tableaux affichent des données.

<table border="1">
   <tr>
      <td>Nom</td>
      <td>Age</td>
   </tr>
</table>

Leçon 8 : Les Formulaires

Créer un formulaire simple.

<form>
   <input type="text">
   <button>Envoyer</button>
</form>

Leçon 9 : Les Boutons

Créer un bouton HTML.

<button>Clique ici</button>

Leçon 10 : Les commentaires

Les commentaires ne s’affichent pas dans la page.

<!-- Ceci est un commentaire -->

Leçon 11 : Les balises div

La balise div sert à organiser les éléments.

<div>
   Contenu
</div>

Leçon 12 : Les span

La balise span sert à modifier une partie du texte.

<span>Texte</span>

Leçon 13 : Les couleurs

Ajouter des couleurs avec style.

<p style="color:red">Bonjour</p>

Leçon 14 : Le CSS interne

Le CSS permet de styliser la page.

<style>
body{
   background:black;
}
</style>

Leçon 15 : Les classes

Une classe peut être utilisée plusieurs fois.

<p class="texte">Bonjour</p>

Leçon 16 : Les ID

Un ID identifie un seul élément.

<h1 id="titre">Bienvenue</h1>

Leçon 17 : Les vidéos

Afficher une vidéo avec video.

<video controls>
   <source src="video.mp4">
</video>

Leçon 18 : Les audios

Ajouter un fichier audio.

<audio controls>
   <source src="music.mp3">
</audio>

Leçon 19 : Les iframes

Afficher une autre page web.

<iframe src="https://example.com"></iframe>

Leçon 20 : Les métadonnées

Les balises meta donnent des informations au navigateur.

<meta charset="UTF-8">

Leçon 21 : Les boutons

Créer des boutons HTML.

<button>Envoyer</button>

Leçon 22 : Les sections

Organiser une page avec section.

<section>
   Contenu
</section>

Leçon 23 : Header et Footer

Créer un en-tête et un pied de page.

<header>Menu</header>
<footer>Copyright</footer>

Leçon 24 : Navigation

Créer un menu avec nav.

<nav>
   <a href="#">Accueil</a>
</nav>

Leçon 25 : Responsive Design

Adapter la page aux téléphones.

@media(max-width:768px){
 body{
   background:gray;
 }
}

Leçon 26 : Les icônes

Ajouter des icônes avec Font Awesome.

<i class="fa fa-home"></i>

Leçon 27 : Les formulaires avancés

Ajouter email et mot de passe.

<input type="email">
<input type="password">

Leçon 28 : Les listes ordonnées

Créer une liste numérotée.

<ol>
  <li>HTML</li>
</ol>

Leçon 29 : Les caractères spéciaux

Afficher des symboles HTML.

&copy;
&euro;

Leçon 30 : Projet Final

Créer un site web complet avec HTML.

<h1>Bienvenue</h1>
<p>Mon premier site web</p>
