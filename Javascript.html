Apprendre JavaScript - 50 Leçons Complètes

Leçon 1 : Introduction à JavaScript

JavaScript permet de rendre un site interactif. C’est le langage utilisé pour les animations, les boutons et les actions dynamiques. 

console.log("Bonjour")

Leçon 2 : Variables

Les variables servent à stocker des données. 

let nom = "Ali"

Leçon 3 : Const

Const crée une variable fixe. 

const age = 20

Leçon 4 : Alert

Alert affiche une boîte de dialogue. 

alert("Bienvenue")

Leçon 5 : Console Log

Console.log affiche des informations dans la console. 

console.log("Test")

Leçon 6 : Les Nombres

JavaScript peut manipuler des nombres. 

let x = 10

Leçon 7 : Les Chaînes

Les chaînes contiennent du texte. 

let texte = "Bonjour"

Leçon 8 : Addition

JavaScript peut additionner. 

let total = 5 + 5

Leçon 9 : Conditions If

If exécute du code selon une condition. 

if(age > 18){
 console.log("Majeur")
}

Leçon 10 : Else

Else exécute une autre action. 

if(age > 18){
 console.log("OK")
}else{
 console.log("Non")
}

Leçon 11 : Fonctions

Les fonctions regroupent du code. 

function salut(){
 alert("Bonjour")
}

Leçon 12 : Paramètres

Les paramètres rendent les fonctions dynamiques. 

function salut(nom){
 console.log(nom)
}

Leçon 13 : Return

Return renvoie une valeur. 

function add(a,b){
 return a+b
}

Leçon 14 : Tableaux

Les tableaux stockent plusieurs valeurs. 

let fruits = ["Pomme","Orange"]

Leçon 15 : Objets

Les objets regroupent plusieurs informations. 

let user = {
 nom:"Ali",
 age:20
}

Leçon 16 : Boucle For

For répète du code. 

for(let i=0;i<5;i++){
 console.log(i)
}

Leçon 17 : While

While répète tant qu’une condition est vraie. 

while(x < 5){
 x++
}

Leçon 18 : Query Selector

QuerySelector sélectionne un élément HTML. 

document.querySelector("h1")

Leçon 19 : InnerHTML

InnerHTML modifie le contenu HTML. 

document.querySelector("h1").innerHTML = "Bonjour"

Leçon 20 : Style

Style change le CSS avec JavaScript. 

document.body.style.background = "black"

Leçon 21 : Add Event Listener

Ajoute un événement. 

button.addEventListener("click", function(){
 alert("Click")
})

Leçon 22 : Click

Click détecte un clic. 

button.onclick = function(){
 alert("Bonjour")
}

Leçon 23 : Input Value

Value récupère une valeur. 

input.value

Leçon 24 : Create Element

CreateElement crée un élément HTML. 

document.createElement("div")

Leçon 25 : Append Child

AppendChild ajoute un élément. 

document.body.appendChild(div)

Leçon 26 : Remove

Remove supprime un élément. 

div.remove()

Leçon 27 : ClassList

ClassList ajoute des classes CSS. 

div.classList.add("active")

Leçon 28 : Toggle

Toggle active ou désactive une classe. 

div.classList.toggle("dark")

Leçon 29 : Math Random

Math.random génère un nombre aléatoire. 

Math.random()

Leçon 30 : Date

Date récupère la date actuelle. 

new Date()

Leçon 31 : SetTimeout

SetTimeout attend avant d’exécuter du code. 

setTimeout(function(){
 alert("Bonjour")
},2000)

Leçon 32 : SetInterval

SetInterval répète du code. 

setInterval(function(){
 console.log("Test")
},1000)

Leçon 33 : JSON

JSON stocke des données. 

let data = {
 nom:"Ali"
}

Leçon 34 : LocalStorage

LocalStorage sauvegarde des données. 

localStorage.setItem("nom","Ali")

Leçon 35 : Switch

Switch gère plusieurs cas. 

switch(x){
 case 1:
 break
}

Leçon 36 : Arrow Function

Les fonctions fléchées sont plus modernes. 

const test = () => {
 console.log("OK")
}

Leçon 37 : Map

Map parcourt un tableau. 

fruits.map(item => console.log(item))

Leçon 38 : Filter

Filter filtre des données. 

notes.filter(note => note > 10)

Leçon 39 : Includes

Includes vérifie une valeur. 

fruits.includes("Pomme")

Leçon 40 : Fetch API

Fetch récupère des données depuis internet. 

fetch("url")

Leçon 41 : Async Await

Async Await simplifie les requêtes. 

async function test(){
}

Leçon 42 : Try Catch

Try Catch gère les erreurs. 

try{
}
catch(error){
}

Leçon 43 : Template String

Les templates simplifient les chaînes. 

`Bonjour ${nom}`

Leçon 44 : Destructuring

Destructuring extrait des valeurs. 

const {nom} = user

Leçon 45 : Spread Operator

Spread copie des données. 

let newArray = [...array]

Leçon 46 : Modules

Les modules séparent le code. 

export default test

Leçon 47 : Classes

Les classes créent des objets. 

class User{}

Leçon 48 : Constructor

Constructor initialise un objet. 

constructor(name){
 this.name = name
}

Leçon 49 : API

Les API permettent de communiquer avec des services. 

fetch("https://api.com")

Leçon 50 : Projet Final

Combine HTML, CSS et JavaScript pour créer une application moderne. 

console.log("Projet terminé")
