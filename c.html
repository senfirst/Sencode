Apprendre le Langage C - 50 Leçons Complètes

Leçon 1 : Introduction au Langage C

Le langage C est un langage puissant créé pour développer des logiciels rapides. 

#include <stdio.h>

Leçon 2 : Premier Programme

Le premier programme affiche souvent "Hello World". 

#include <stdio.h>

int main(){

printf("Hello World");

return 0;
}

Leçon 3 : Fonction main()

La fonction main est le point de départ du programme. 

int main(){
}

Leçon 4 : printf()

printf permet d’afficher du texte. 

printf("Bonjour");

Leçon 5 : Variables

Les variables stockent des données. 

int age = 20;

Leçon 6 : Types de Données

Le C possède plusieurs types de données. 

int
float
char

Leçon 7 : Les Entiers

int stocke les nombres entiers. 

int nombre = 10;

Leçon 8 : Les Décimaux

float stocke les nombres décimaux. 

float prix = 10.5;

Leçon 9 : Les Caractères

char stocke un caractère. 

char lettre = 'A';

Leçon 10 : scanf()

scanf permet de lire les données utilisateur. 

scanf("%d",&age);

Leçon 11 : Les Opérateurs

Les opérateurs servent aux calculs. 

+
-
*
/

Leçon 12 : if

if exécute une condition. 

if(age > 18){
printf("Majeur");
}

Leçon 13 : else

else exécute une autre action. 

else{
printf("Mineur");
}

Leçon 14 : else if

else if ajoute plusieurs conditions. 

else if(age == 18)

Leçon 15 : switch

switch simplifie plusieurs choix. 

switch(note){
case 10:
break;
}

Leçon 16 : Boucle for

for répète des instructions. 

for(int i=0;i<5;i++)

Leçon 17 : Boucle while

while répète tant qu’une condition est vraie. 

while(x < 5)

Leçon 18 : do while

do while exécute au moins une fois. 

do{
}
while(x<5);

Leçon 19 : Tableaux

Les tableaux stockent plusieurs valeurs. 

int notes[5];

Leçon 20 : Chaînes de Caractères

Les chaînes utilisent char. 

char nom[] = "Ali";

Leçon 21 : Fonctions

Les fonctions organisent le code. 

void salut(){
printf("Bonjour");
}

Leçon 22 : return

return renvoie une valeur. 

return 0;

Leçon 23 : Paramètres

Les fonctions peuvent recevoir des paramètres. 

int somme(int a,int b)

Leçon 24 : Pointeurs

Les pointeurs stockent des adresses mémoire. 

int *p;

Leçon 25 : Adresse Mémoire

& affiche une adresse mémoire. 

&a

Leçon 26 : Structures

Les structures regroupent plusieurs données. 

struct User{
char nom[20];
};

Leçon 27 : Typedef

typedef crée un alias. 

typedef int entier;

Leçon 28 : Fichiers

Le C peut lire des fichiers. 

FILE *fichier;

Leçon 29 : fopen()

fopen ouvre un fichier. 

fopen("test.txt","r");

Leçon 30 : fclose()

fclose ferme un fichier. 

fclose(fichier);

Leçon 31 : fprintf()

fprintf écrit dans un fichier. 

fprintf(fichier,"Bonjour");

Leçon 32 : fscanf()

fscanf lit un fichier. 

fscanf(fichier,"%s",nom);

Leçon 33 : malloc()

malloc réserve de la mémoire. 

malloc(sizeof(int));

Leçon 34 : free()

free libère la mémoire. 

free(p);

Leçon 35 : Constantes

const crée une valeur fixe. 

const int x = 5;

Leçon 36 : Macros

#define crée une macro. 

#define PI 3.14

Leçon 37 : break

break arrête une boucle. 

break;

Leçon 38 : continue

continue passe à l’itération suivante. 

continue;

Leçon 39 : Enum

enum crée une liste de constantes. 

enum Jour{
Lundi,
Mardi
};

Leçon 40 : Union

union partage la mémoire. 

union Data{
int x;
};

Leçon 41 : Bibliothèques

Les bibliothèques ajoutent des fonctions. 

#include <math.h>

Leçon 42 : sqrt()

sqrt calcule une racine carrée. 

sqrt(25);

Leçon 43 : strlen()

strlen compte les caractères. 

strlen(nom);

Leçon 44 : strcpy()

strcpy copie une chaîne. 

strcpy(a,b);

Leçon 45 : strcmp()

strcmp compare deux chaînes. 

strcmp(a,b);

Leçon 46 : Tableaux 2D

Les tableaux 2D créent des matrices. 

int tab[3][3];

Leçon 47 : Arguments main

main peut recevoir des arguments. 

int main(int argc,char *argv[])

Leçon 48 : Compilation

Le code C doit être compilé. 

gcc main.c -o app

Leçon 49 : Debug
