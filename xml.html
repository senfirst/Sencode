XML
Apprendre XML
Guide complet de A à Z
50 Leçons
01

Introduction à XML

XML signifie Extensible Markup Language. Il sert à stocker et transporter des données de façon structurée et lisible.

<nom>Ali</nom>
02

Déclaration XML

La déclaration en tête du fichier indique la version XML utilisée et l'encodage des caractères.

<?xml version="1.0" encoding="UTF-8"?>
03

Balises XML

Les balises encadrent les données. Une balise ouvrante et une balise fermante délimitent un élément.

<ville>Dakar</ville>
04

Balise Racine

Chaque document XML possède une seule balise racine qui englobe tous les autres éléments.

<users>
  <user>Ali</user>
</users>
05

Les Éléments

Les éléments sont les blocs de base de XML. Ils stockent des informations entre leurs balises.

<age>20</age>
06

Les Attributs

Les attributs ajoutent des informations supplémentaires à un élément. Ils s'écrivent dans la balise ouvrante.

<user id="1" role="admin"></user>
07

Commentaires XML

Les commentaires permettent d'annoter le code sans que ce texte soit traité par le parseur.

<!-- Ceci est un commentaire -->
08

Imbrication

Les balises peuvent être imbriquées les unes dans les autres pour créer une hiérarchie.

<user>
  <nom>Ali</nom>
  <ville>Dakar</ville>
</user>
09

XML Bien Formé

Un XML bien formé respecte toutes les règles syntaxiques : balises fermées, imbrication correcte, etc.

<note>Bonjour le monde</note>
10

Sensibilité à la Casse

XML est sensible à la casse. <Nom> et <nom> sont deux éléments différents.

<Nom>Valeur A</Nom>
<nom>Valeur B</nom>
11

Fermeture des Balises

Contrairement au HTML, toutes les balises XML doivent être fermées explicitement.

<titre>Apprendre XML</titre>
12

Valeurs d'Attributs

Les valeurs des attributs doivent toujours être entourées de guillemets simples ou doubles.

<book id="5" lang="fr"></book>
13

CDATA

CDATA permet d'inclure du texte brut sans interprétation XML, utile pour intégrer du HTML ou du code.

<![CDATA[
  <html></html>
]]>
14

Entités XML

Les entités remplacent les caractères spéciaux réservés par XML pour éviter les erreurs de parsing.

&lt;   → <
&gt;   → >
&amp;  → &
15

XML et Données

XML est conçu pour stocker et échanger des données entre systèmes différents de manière indépendante.

<produit>
  <nom>Téléphone</nom>
  <prix>199</prix>
</produit>
16

Structure Hiérarchique

XML organise les données en arborescence, avec des relations parent-enfant entre les éléments.

<ecole>
  <classe>
    <eleve>Ali</eleve>
  </classe>
</ecole>
17

XML vs HTML

HTML affiche les données dans un navigateur. XML stocke et transporte des données sans logique d'affichage.

<!-- HTML : affichage -->
<p>Bonjour</p>

<!-- XML : données -->
<message>Bonjour</message>
18

XML vs JSON

JSON est plus léger et courant pour les APIs web. XML est plus verbeux mais plus structuré et validable.

<!-- XML -->
<nom>Ali</nom>

<!-- JSON équivalent -->
{ "nom": "Ali" }
19

Liste XML

XML représente les listes en répétant des éléments du même nom au sein d'un élément parent.

<fruits>
  <fruit>Pomme</fruit>
  <fruit>Mangue</fruit>
  <fruit>Banane</fruit>
</fruits>
20

Balise Vide

Une balise sans contenu peut s'écrire sous forme auto-fermante avec le slash avant le chevron fermant.

<br/>
<image src="photo.jpg"/>
21

Namespaces

Les namespaces permettent d'éviter les conflits lorsqu'on mélange des vocabulaires XML différents.

<h:table xmlns:h="html">
  <h:tr></h:tr>
</h:table>
22

Encodage UTF-8

L'encodage UTF-8 permet de gérer tous les caractères internationaux, accents et symboles spéciaux.

<?xml version="1.0" encoding="UTF-8"?>
<message>Héllo Wörld</message>
23

XPath

XPath est un langage de requête pour naviguer et sélectionner des nœuds dans un document XML.

/librairie/book/title
//author
book[@id='1']
24

XSLT

XSLT transforme un document XML en un autre format (HTML, texte, autre XML) grâce à des feuilles de style.

<xsl:stylesheet version="1.0">
  <xsl:template match="/">
  </xsl:template>
</xsl:stylesheet>
25

DTD

La DTD (Document Type Definition) définit la structure autorisée d'un document XML.

<!DOCTYPE note [
  <!ELEMENT note (message)>
  <!ELEMENT message (#PCDATA)>
]>
26

Validation XML

Un document XML valide respecte les règles d'une DTD ou d'un schéma XML (XSD) associé.

<!-- Valider avec un schéma -->
<root xmlns:xsi="..."
  xsi:noNamespaceSchemaLocation="schema.xsd">
</root>
27

XML Schema (XSD)

L'XML Schema décrit les types de données, les contraintes et la structure attendue d'un document XML.

<xs:schema xmlns:xs="...">
  <xs:element name="nom" type="xs:string"/>
</xs:schema>
28

Élément Complexe

Un élément complexe contient d'autres éléments enfants ou des attributs, contrairement aux éléments simples.

<personne>
  <nom>Ali</nom>
  <age>25</age>
</personne>
29

Élément Simple

Un élément simple contient uniquement du texte, sans éléments enfants ni attributs.

<nom>Ali</nom>
<prix>29.99</prix>
30

XML et Base de Données

XML peut servir de format d'échange avec des bases de données relationnelles ou NoSQL.

<clients>
  <client id="1">
    <nom>Fatou</nom>
  </client>
</clients>
31

Flux RSS

RSS est un format XML standardisé pour distribuer des fils d'actualités sur le web.

<rss version="2.0">
  <channel>
    <title>Mon Blog</title>
  </channel>
</rss>
32

Sitemap XML

Les fichiers sitemap.xml aident les moteurs de recherche à indexer les pages d'un site web.

<urlset xmlns="...">
  <url>
    <loc>https://exemple.com</loc>
  </url>
</urlset>
33

SOAP

SOAP (Simple Object Access Protocol) utilise XML pour structurer les messages entre services web.

<soap:Envelope>
  <soap:Body>
    <requete/>
  </soap:Body>
</soap:Envelope>
34

XML et Android

Android utilise XML pour définir les interfaces utilisateur, les thèmes et les ressources de l'application.

<TextView
  android:text="Bonjour"
  android:textSize="16sp"/>
35

XML et Java

Java fournit des APIs comme DOM et SAX pour lire, créer et manipuler des documents XML.

DocumentBuilderFactory factory =
  DocumentBuilderFactory.newInstance();
DocumentBuilder builder =
  factory.newDocumentBuilder();
36

XML et PHP

PHP propose des fonctions natives comme SimpleXML pour charger et manipuler facilement du XML.

$xml = simplexml_load_file('data.xml');
echo $xml->nom;
37

XML et Python

Python dispose de bibliothèques comme xml.etree.ElementTree pour traiter des fichiers XML.

import xml.etree.ElementTree as ET
tree = ET.parse('fichier.xml')
root = tree.getroot()
38

Parser XML

Un parser XML analyse le document et construit une représentation exploitable par programme.

const parser = new DOMParser();
const xmlDoc = parser.parseFromString(
  xmlStr, "text/xml"
);
39

DOM XML

Le DOM représente un document XML sous forme d'arbre de nœuds navigables et modifiables.

const nodes =
  xmlDoc.getElementsByTagName("nom");
console.log(nodes[0].textContent);
40

SAX Parser

SAX lit le XML de façon séquentielle, événement par événement — idéal pour les grands fichiers.

SAXParserFactory factory =
  SAXParserFactory.newInstance();
SAXParser parser =
  factory.newSAXParser();
41

Attribut Required

Dans un schéma XSD, on peut rendre un attribut obligatoire avec use="required".

<xs:attribute name="id"
  type="xs:integer"
  use="required"/>
42

Séquence XSD

L'élément xs:sequence impose que les éléments enfants apparaissent dans un ordre précis.

<xs:sequence>
  <xs:element name="nom"/>
  <xs:element name="age"/>
</xs:sequence>
43

minOccurs

minOccurs définit le nombre minimum d'occurrences d'un élément. Zéro le rend optionnel.

<xs:element name="phone"
  minOccurs="0"
  maxOccurs="3"/>
44

maxOccurs

maxOccurs="unbounded" permet un nombre illimité de répétitions d'un élément.

<xs:element name="item"
  minOccurs="1"
  maxOccurs="unbounded"/>
45

Documentation XML

XML peut inclure des éléments de documentation dans les schémas pour décrire les champs.

<xs:annotation>
  <xs:documentation>
    Identifiant unique du client
  </xs:documentation>
</xs:annotation>
46

Sécurité XML

Les attaques XXE (XML External Entity) exploitent les parseurs XML. Toujours désactiver les entités externes.

<!-- Éviter les entités externes -->
<!ENTITY xxe SYSTEM
  "file:///etc/passwd">
47

XML et APIs

Certaines APIs REST ou SOAP retournent encore des réponses en XML, notamment dans les systèmes anciens.

<response status="200">
  <data>
    <result>OK</result>
  </data>
</response>
48

Avantages de XML

XML est lisible par l'humain, extensible, indépendant de la plateforme et largement supporté.

<avantages>
  <lisible>oui</lisible>
  <extensible>oui</extensible>
  <portable>oui</portable>
</avantages>
49

Inconvénients de XML

XML est verbeux et volumineux comparé à JSON. Le parsing peut être lent sur de très grands fichiers.

<inconvenients>
  <verbeux>oui</verbeux>
  <lourd>oui</lourd>
</inconvenients>
50
